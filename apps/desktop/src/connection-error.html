A interface da loja não pôde ser aberta

O aplicativo não conseguiu carregar a página do servidor local ou do computador principal.

Se este é o computador principal: feche a Loja de Roupas e abra novamente. Confira se o banco PostgreSQL está em funcionamento.

Se este é um terminal: verifique a rede LAN e se o computador principal está ligado.

O aplicativo tenta reconectar sozinho a cada 5 segundos. Esta tela some assim que a loja responder.

Não é necessário reinstalar nem apagar o banco de dados. Seus arquivos e vendas não foram removidos.
